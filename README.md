# ADL-TT-Library

A collection of TT (Thinktank) ADL algorithms and knowledge base resources.

## Quick Start

### Clone the Repository

```bash
git clone https://github.com/Mathur-Git/ADL-TT-Library.git
cd ADL-TT-Library
```

### For Claude Code Users

If you're using Claude Code, you can open this repository directly:

1. **Via Claude Code CLI:**
   ```bash
   claude-code /path/to/ADL-TT-Library
   ```

2. **Via Claude.ai:**
   - Go to [claude.ai/code](https://claude.ai/code)
   - Click "Open a folder"
   - Navigate to and select the cloned repository folder

3. **Via Desktop/IDE:**
   - Open Claude Code (desktop app or IDE extension)
   - Open the folder containing the cloned repository

## Repository Structure

- `adl-kb/` - Knowledge base with ADL guides and references
- `trade-kb/` - Trading-related documentation
- `.claude/` - Claude Code configuration

## Getting Started with Claude

Once you have the repository open in Claude Code:

1. Ask Claude questions about the algorithms and documentation
2. Claude can read and reference files in the knowledge base
3. Use Claude to help understand, modify, or extend the algorithms

Example prompts:
- "Explain the structure of the ADL knowledge base"
- "Help me understand the algo-types guide"
- "Show me the formula reference"

## Requirements

- Git (to clone the repository)
- Claude Code (to work with the repository interactively)
- Text editor or IDE of choice

## Support

For questions about the algorithms or documentation, refer to the knowledge base files in `adl-kb/` and `trade-kb/`.
