# Formatting charts

> Category: **Analytics** · [Source](https://library.tradingtechnologies.com/trade/analytics/charts/task-charts/formatting-charts/)
>
> **Interpreted in:** [Charts & Analytics § Trading from a chart](../../../../guides/charts-and-analytics.md#trading-from-a-chart)

To format and configure your chart, you can:

* [Change the chart type](#chart)
* [Change the time interval](#interval)
* [Display daily values](#dvb)
* [Display historical data](#history)
* [Move the price axis](#price)
* [Group charts together](#group)
* [Use LTP to build spread charts](#spread-ltp)

## Changing the chart type

You can display intervals of historical data using different [chart types](../description-charts/chart-types.md) or styles.

To change the chart type:

1. Click ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-menu-4.png) (the chart menu icon) in the top left corner of the chart and click ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-chart-type-1.png) (the Chart Type icon) in the Chart menu.
2. Select a chart type.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-select-chart-type.png)

## Changing the interval

The time interval settings determine how often the chart displays historical market data for the instrument. The default interval is one minute.

To change the time interval:

1. Click ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-menu-5.png) (the chart menu icon) in the top left corner of the chart and click ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-intervals-1.png) (the Intervals icon) in the Chart menu.
2. Select an interval.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-select-chart-interval.png)
3. Optionally, you can click ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-search-4.png) (the Search Instruments icon) and type a numeric value in the search field to display the matching intervals in the Search results.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-charts-interval-search.png)

## Displaying daily values

By default, the Chart widget displays a daily value box in the top-left corner that includes the following information:

* **O** — Opening price for the current day
* **H** — Highest price for the current day
* **L** — Lowest price for the current day
* **C** — Closing price for the previous trading day
* **Δ** — Net change between the previous closing price and the current last price
* **V** — Total volume traded for the current day

Right-click the daily value box to show/hide the border around the daily values. By default, the daily value box is displayed with the border hidden.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-border.png)

You can display the daily value box with a vertical or horizontal orientation by right-clicking on the box and selecting the alternate orientation.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-vertical.png)

You can click-and-hold and drag-and-drop the daily value box to different locations on the chart.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-daily.png)

You can also hide (or show) the box by selecting the desired effect from the widget’s right-click context menu.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-hide.png)

## Displaying historical data

You can click-and-hold in the chart and drag the cursor to the right or left to change the range of time displayed in the chart.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-history.png)

## Moving the price axis

Click-and hold the price axis, then drag the mouse up or down to change the range of prices displayed in the chart.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-price.png)

## Grouping charts together

You can right-click in the title bar to [create a widget
group](../../../overview/widgets/description-widgets/widget-groups.md) for your Charts.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chart-group.png)

## Use LTP to build spread charts

By default, charts use the difference of Bid prices of spread legs when building a chart for Autospreader spreads. If desired, you can use the difference in LTP (last traded price) of the legs instead.

To use LTP, you can right-click on the price (Y) axis and select LTP for the Spread Formula in the context menu.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chart-build-ltp.png)
