# Using technical indicators

> Category: **Analytics** · [Source](https://library.tradingtechnologies.com/trade/analytics/charts/task-charts/using-technical-indicators/)
>
> **Interpreted in:** [Charts & Analytics § Trading from a chart](../../../../guides/charts-and-analytics.md#trading-from-a-chart) · [Charts & Analytics § Technical indicators](../../../../guides/charts-and-analytics.md#technical-indicators)

The Chart widget supports many [technical indicators](../description-charts/technical-indicators.md) that you can add to the chart. The widget also allows you to add a technical indicator (TI) to another technical indicator (study on a study).

To add a technical indicator

1. Click ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-menu-2.png) (the chart menu icon) in the top left corner of the chart and click ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-tech-indicators-1.png) (the Technical Indicators icon) in the Chart menu. Then, scroll the list and select an indicator.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-study.png)

     
   You can also click the ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-search-3.png) and start typing the name of an indicator.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-search.png)
2. Configure the indicator as needed and click **Create**.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-study-create.png)

     
   The study appears on the chart:

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-study-add.png)

## Modifying a technical indicator on a chart

For a technical indicator, such as the Moving Average, that overlays the chart, hover over and right-click on a technical indicator on the chart and select **Edit** from the context menu.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-edit.png)

For technical indicators that appear below the chart (e.g., Bollinger Bandwidth), use their edit icons to modify them.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-options.png)

## Removing a technical indicator from a chart

To remove a technical indicator, hover over and right-click on a technical indicator and select **Delete** for click the delete icon..

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-remove.png)

## Adding a technical indicator to a technical indicator

The Chart widget provides the ability to add a technical indicator that uses the output from another technical indicator on the chart as input to create a study on a study.

1. Click ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-menu-3.png) (the chart menu icon) in the top left corner of the chart and click ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-tech-indicators-2.png) (the Technical Indicators icon) in the Chart menu.
2. Add and configure the first indicator (e.g., Moving Average).
     
     
   The Moving Average indicator appears on the chart. This indicator will act as a function using the bar data in the chart as input.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-study-add-1.png)
3. Click ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-tech-indicators-3.png) in the Chart menu and select the second technical indicator (e.g., ATR Bands) that you would like to add to the chart.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-study1.png)
4. Click **Field** in the second indicator’s configuration window and select the first indicator. The second indicator will serve as a function using the output from the first indicator as input.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-study2.png)
5. Click **Create**.
     
     
   The output from the first indicator (study) is now an input to the second indicator (study). The output from the study on a study is reflected in the chart.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-chart-study3.png)
