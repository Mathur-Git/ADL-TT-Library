# Adding a series

> Category: **Analytics** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/analytics/charts/task-charts/adding-a-series/)

The Add Series feature lets you compare multiple instruments on the same chart. A series uses a line chart, along with an independent price axis, for each instrument in the series. You can add up to two more instruments to the base instrument’s chart. You might use a series to compare different instruments that you think might related in some way, such as consecutive expiries of a single instrument or multiple instruments for related products. For example, the following chart uses the Add Series feature to display the activity for the Jun18, Jul18, and Aug18 BRN (Brent Crude) instruments.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-series-example.png)

In addition to the visual cues shown in a series, hovering over any curve also displays information about all of the line charts that intersect at the point.

**Note**: Series support only the Line chart type.

To add a series to a chart:

1. Open a chart with the base instrument, using a Line chart type. In this case, we will display the price relationship between crude (CL Jun18), natural gas (NG Jun18) and RBOB gas (RB Jun18).

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-add-series-1.png)
2. From the Chart menu, click ![the More icon](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-comparison-2.png) and select **Add Series**.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-add-series-2.png)
3. Use **Search** to select the next instrument to add to the chart.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-add-series-3.png)

     
   A line chart and price axis are added to the chart for the selected insrument, and its name and color are added to the legend in the lower-left section of the chart.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-add-series-3a.png)
4. If desired, use the same process to add the last series.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-add-series-4.png)
5. Hover over a point where the two or more curves intersect to show the price for each series at that point in time.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/chrt-add-series-5.png)

To remove a series from the chart, click the delete icon following the instrument’s name in the chart’s legend.
