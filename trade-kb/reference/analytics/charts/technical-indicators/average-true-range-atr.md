# Average True Range (ATR)

> Category: **Analytics** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/analytics/charts/technical-indicators/average-true-range-atr/)

The Average True Range (ATR) study measures
the size of the period’s range, and takes into account any gap from
the close of the previous period.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/average-true-range.png)

## Configuration Options

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/average-true-range-1.png)

* **Period**: Number of bars to use in the calculations.
* **Color Selectors**: Colors to use for graph elements.
* **Display Axis Label**: Whether to display the most recent value on the Y axis.

## Formula

\[Average\;True\;Range = average(TR, n)\]

where:

\(TR = max(High\_{t} – Close\_{t-1}\;,\;Close\_{t-1} – Low\_{t}\;,\;High\_{t} – Low\_{t})\)\(n = period\)
