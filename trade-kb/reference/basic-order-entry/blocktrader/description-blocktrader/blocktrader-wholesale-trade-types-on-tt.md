# Blocktrader wholesale trade types on TT

> Category: **Basic Order Entry** · [Source](https://library.tradingtechnologies.com/trade/basic-order-entry/blocktrader/description-blocktrader/blocktrader-wholesale-trade-types-on-tt/)
>
> **Interpreted in:** [Order Types & Execution § Block trading](../../../../guides/order-types-and-execution.md#block-trading)

The following table shows the wholesale trade types supported per exchange in Blocktrader on TT.

| Exchange | Blocktrader Wholesale Trade Types |
| --- | --- |
| CME | Request for Cross |
| EEX | Block |
| Eurex | * Cross * Block * Exchange for Swap * Volatility * EFP – Exchange for Physical Fixed Income * EFP – Exchange for Physical Index Futures |
| Euronext | * Against Actual * Exchange for Swap * Large in Scale – 1 Sided * Large in Scale – 2 Sided * Request for Cross |
| GFO-X | * Block * EFRP |
| HKEX | * Interbank – 1 Sided * Internal * Internal Strategy |
| ICE | * Exchange for Swap * Cross |
| ICE\_L | * Cross * Basis * Block * Other Block Types: Asset Allocation |
| JPX | * J Net One Sided * J Net Cross |
| LME | Cross |
| MEFF | Cross |
| MX | Committed – 1 Sided |
| NDAQ\_EU | * Financial Derivatives   * FD – Block   * FD – Standard   * FD – Standard Outside   * FD – Off Hours   * FD – Exch Granted   * FD – Exch Granted exceed Max Lot   * FD – Exch Granted exceed Max Lot Off Hours   * FD – Exch Granted Late   * FD – Flex Contract Conversion * Commodity Derivatives   * CD – Standard   * CD – Standard Outside Spread   * CD – Combination   * CD – Internal   * CD – Correction * Commodities Freight   * F01 Block – Standard   * F03 Block – Combination   * F16 Block – Combination buyer only   * F17 Block – Combinationi seller only   * F04 EFS/EFP   * F05 Block – Internal   * F07 Block – Correction   * F18 EFS/EFP – Combination   * F19 EFS/EFP – Combination buyer only   * F20 EFS/EFP – Combination seller only * Commodities – Iron Ore   * Standard Trade report   * OTC, Combination   * OTC, Combination buyer only   * OTC, Combination seller only |
| NZX | * Block * EFP – Exchange for Physical |
| SGX | * One Sided * Two Sided |
| TFEX | * One Sided * Exchange for Physical via the **Trade Purpose** field. |
