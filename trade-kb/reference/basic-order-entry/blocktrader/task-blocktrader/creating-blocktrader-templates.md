# Creating Blocktrader templates

> Category: **Basic Order Entry** · [Source](https://library.tradingtechnologies.com/trade/basic-order-entry/blocktrader/task-blocktrader/creating-blocktrader-templates/)
>
> **Interpreted in:** [Order Types & Execution § Block trading](../../../../guides/order-types-and-execution.md#block-trading)

Templates allow you to save frequently-used Blocktrader settings for future use. They let you quickly select a set of predefined values from a template list. You can create multiple templates for a specific blocktrade, as well as create different sets of templates for different blocktrades. These templates can be selected from the drop-down to populate the order parameter fields with the saved values.

### Creating a Blocktrader template

To create a Blocktrader template:

1. Select **Add template** from the **Template** drop-down menu.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/blocktrader-template-add.png)

2. In the **Add template** dialog, enter a **Name** for the template, and click **Save**.

   The template is added to the drop-down.
3. Update the desired order parameter values, and click the ![Save](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-save-7.png) icon.

### Using a Blocktrader template

To use a Blocktrader template:

1. From the **Template** drop-down, select the template desired.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/blocktrader-template-select.png)

2. Make any changes to the parameters if needed before confirming the trade.

### Modifying a Blocktrader template

To modify a Blocktrader template:

1. From the **Template** drop-down, select the template you want to modify.
2. Update the desired parameter values, and click the ![Save](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-save-8.png) icon.

### Setting a default Blocktrader template

The template drop-down menu lets you specify a default template (indicated by the yellow star) that will appear pre-selected every time you select the associated exchange. You can revert to the default system settings by selecting the **<None>** option.

To set a default Blocktrader template:

1. Click the **Template** drop-down menu.
2. Click the ![Star](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-yellow-star-3.png) icon for the template you want to make the default.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/blocktrader-template-default.png)

### Deleting a Blocktrader template

To delete a Blocktrader template:

1. Click the **Template** drop-down menu.
2. Click the ![Trash Can](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-delete-algo-template-1.png) icon for the template you want to delete.
