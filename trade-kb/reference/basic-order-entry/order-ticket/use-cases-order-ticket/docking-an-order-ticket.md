# Docking an Order Ticket

> Category: **Basic Order Entry** · [Source](https://library.tradingtechnologies.com/trade/basic-order-entry/order-ticket/use-cases-order-ticket/docking-an-order-ticket/)

When you dock an Order Ticket to a Market Grid, you create a single widget that automatically updates when you
select different contracts.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/ot-docked-to-mg-overview.png)

To dock an Order Ticket:

1. Open an Order Ticket from a Market Grid.
2. From the right-click context menu for the Order Ticket, select **Create group widget**.
3. Drag the Order Ticket to the top or bottom of the Market Grid.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/ot-dock-drag.png)
4. Release the mouse button to create the widget group.
