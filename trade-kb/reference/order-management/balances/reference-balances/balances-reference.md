# Balances Reference

> Category: **Order Management** · [Source](https://library.tradingtechnologies.com/trade/order-management/balances/reference-balances/balances-reference/)
>
> **Interpreted in:** [Order Management & Risk § Accounts & balances](../../../../guides/order-management-and-risk.md#accounts-balances)

The Balances widget can display the following values – there are three columns:

* Previous Settlement — values updated by the Broker / FCM as of the most recent upload.
* Current Estimate — calculated using current positions / working orders / P/L.
* Change — difference between values for Prior Settlement and Current Estimate.

## Field Names

|  |  |
| --- | --- |
| Total Balance | Total cash account balance at the start of the day. |
|  |  |
| --- | --- |
| Collateral | The margin value of any securities (e.g. T-Bills) in the account, normally 95% of the face value. |
| Open Trade Equity | The open trade equity (marked to market P/L) of non-Options positions, calculated using midpoint. |
| Long Option Val | The net value of open long option positions, displayed for supported markets. |
| Short Option Val | The net value of open short option positions, displayed for supported markets. |
| Net Option Val | The net value of open option positions, displayed for supported markets. |
| Liquidating Val | The value of the account if all positions were liquidated based on the estimated fill settlement prices. |
| Total Equity | The total trade equity (marked to market P/L) on open positions plus total balance. |
| Initial Margin Req | The margin equity needed to initiate a position. |
| Maintenance Margin Req | The minimum margin equity required to be maintained by an account. |
| Margin Excess | The margin equity the account has, in excess or deficit of initial margin requirement (Includes Net Option Value where available) |
| Margin Scale Up | The percent margin applied to an account. |
