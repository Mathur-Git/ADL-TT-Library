# Balances Overview

> Category: **Order Management** · [Source](https://library.tradingtechnologies.com/trade/order-management/balances/description-balances/balances-overview/)
>
> **Interpreted in:** [Order Management & Risk § Accounts & balances](../../../../guides/order-management-and-risk.md#accounts-balances)

The Balances widget allows you to view real-time account balances and margin requirements of your account.

Balances are displayed based on the currency selected for your account. Values originating in other currencies are converted automatically.

The Balances widget can be found in Widgets > Miscellaneous.

Note An account must first be selected for Balance and Margin values to display. See [Configuring a Balances Widget](../task-balances/configuring-balances.md).

A maximum of one Balances widget can be opened on a workspace and it can be grouped with the Account List widget for quick navigation between multiple accounts.

The refresh interval is ~10 seconds. A manual refresh can be completed anytime by clicking the icon in the bottom right.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/bal-balances.png)

The Balances widget currently only supports Accounts. Risk Groups are not supported at this time.
