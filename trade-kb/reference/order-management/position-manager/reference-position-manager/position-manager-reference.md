# Position Manager reference

> Category: **Order Management** · [Source](https://library.tradingtechnologies.com/trade/order-management/position-manager/reference-position-manager/position-manager-reference/)

## Context menu

Right-click in the widget to open the context menu and select the following actions:

* **Open**: Open the selected contract in an MD Trader, Order Ticket, Time and Sales, or Charts widget.
* **Clone selected rows**: Copies the selected fills or SODs and displays them as new rows that can be modified and published.
* **Export rows**: Exports data to a comma-separated values (CSV) file for all rows or selected rows in the Positions widget. Use Shift-click to select multiple rows.
* **Clear all filters**: Turns off all filters you may have set for each column.
* **Settings**: Allows you to customize settings for the widget.
