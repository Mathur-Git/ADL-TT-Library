# Account List Reference

> Category: **Order Management** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/order-management/account-list/reference-account-list/account-list-reference/)

## Available settings

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/trade-account-list-settings.png)

**Ignore global Account List broadcasts** — Configures the widget to ignore account selections made in an Account List. When checked (enabled), the widget ignores account selections broadcast by an Account List widget.
