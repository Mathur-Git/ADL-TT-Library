# Launching an OMA in the Floating Order Book

> Category: **Order Management** · [Source](https://library.tradingtechnologies.com/trade/order-management/floating-order-book/task-floating-order-book/launching-an-oma-in-the-floating-order-book/)

If you have access to Order Management Algos (OMAs), you can launch them for an order from the Floating Order Book. To launch an algo for an existing order:

1. Click the arrow in the working order cell to open the Floating Order Book.
2. Click ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-oma.png) to launch an OMA for a single order.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/fob-oma-1.png)

   **Tip**: You can select multiple orders and launch an OMA for each order by clicking the OMA button at the bottom of the grid. The OMA button displays the number of orders selected (e.g., OMA (2))

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/fob-oma-1a.png)
3. Select the OMA to run.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/fob-oma-2.png)
4. Enter the algo parameters and click ![Launch](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/btn-green-launch.png).

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/fob-oma-3.png)
