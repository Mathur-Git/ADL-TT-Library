# Floating Order Book overview

> Category: **Order Management** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/order-management/floating-order-book/description-floating-order-book/floating-order-book-overview/)

The Floating Order Book displays all of the individual orders for a specific instruments at a specific price level. You can launch a Floating Order Book from MD Trader, Market Grid, and Spread Matrix. After launching a Floating Order Book, you can modify or delete individual or multiple orders.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/fob-overview.png)

### Floating Order Book (FOB) Hotkey Trading

The Floating Order Book (FOB) responds to keystroke presses, specifically:

* Esc (Escape) = close the FOB
* Tab = navigate cells from left to right ● Enter = submit pending changes
* Up/Down Arrows = navigate up and down between multiple order rows

When the FOB is launched, focus is set on the price cell of the first order, with the value highlighted and ready to accept modifications from the keyboard. If the price column is not included as one of the default FOB columns, then no cell will have focus upon FOB launch.
