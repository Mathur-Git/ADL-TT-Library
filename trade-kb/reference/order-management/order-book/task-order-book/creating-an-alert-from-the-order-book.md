# Creating an Alert from the Order Book

> Category: **Order Management** · [Source](https://library.tradingtechnologies.com/trade/order-management/order-book/task-order-book/creating-an-alert-from-the-order-book/)
>
> **Interpreted in:** [Order Management & Risk § Fills & Order Book](../../../../guides/order-management-and-risk.md#fills-order-book)

Price alerts can be created by a right-click menu item of “Create price alert” that appears on individually selected orders from the Order Book. When the menu item is selected, the Alert Manager launches seeded with that order instrument as a price alert ready to type in the price for the alert.
