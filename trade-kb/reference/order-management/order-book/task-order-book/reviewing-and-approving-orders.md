# Reviewing and approving orders

> Category: **Order Management** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/order-management/order-book/task-order-book/reviewing-and-approving-orders/)

Using the following columns in the Order Book widget, you can inform users sharing an account that an order is
available for review as a form of order confirmation:

* **Review** — Indicates a request for a review of a care order.
* **ReviewedAcct** — Shows who requested the review of the care order.
* **Approve** — Indicates that a care order has been approved.
* **ApprovedAcct** — Shows who reviewed and approved the care order.

When using these optional columns in the Order Book to review and approve orders, consider the following:

* Any of the users sharing the same account can approve the parent order (e.g., care order) or child order,
  including full or view-only administrators without trade permissions.
* Reviewing and approving an order is not required to be done before the order is submitted to the exchange.

To inform users that an order is available to be reviewed, click the checkbox in the **Review** column for that
order. After the checkbox is checked, the user who initiated the request is displayed in the **ReviewedAcct**
column.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/co-review.png)

To approve an order after reviewing it, click the checkbox in the **Approve** column. After the checkbox is
checked, the user approving the trade is displayed in the **ApprovedAcct** column.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/co-review-approve1.png)

After an order is approved, the alias of the user approving the trade is also displayed in the **Approved** column
in the Audit Trail.
