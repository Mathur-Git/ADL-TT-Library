# Account & User Restrictions Reference

> Category: **Order Management** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/order-management/account-user-restrictions/reference-account-user-restrictions/account-user-restrictions-reference/)

The Account & User Restrictions widget contains the following columns in the “Account Restrictions” and “User Restrictions” tabbed views.

| Column | Description |
| --- | --- |
| Apply | Restrictions are applied to the account. |
| Modify Orders | Orders can be modified in the account. |
| Place Orders | Orders can be submitted in the account. |
| TT API | Orders can be submitted using a REST API or FIX trading application. |
| TT Order Types | Synthetic order types can be submitted in the account. |
| Autospreader | Autospreader orders can be submitted in the account. |
| Submit Block/Cross Orders | Block/Cross orders can be submitted in the account. |
| Market | The account allows Market orders. |
| GTC/GTDate | The account allows GTC or GTDate orders. |
| OBO | On Behalf Of (OBO) order permission. |
| Pause Algos | Algos can be paused in the account. |
| Resume Algos | Algos can be resumed in the account. |
| Update positions | Shows whether the position in this account can be updated manually. |
| RFQ / Cross | Shows whether a user can submit Block and/or Cross Wholesale orders with this account. |
| Mobile | Indicates whether the account can be used to submit orders using a mobile device. |
| TT Algo SDK | Indicates whether a user can submit an order via a TT Algo SDK application using this account. |
| ADL | Shows whether a user can submit an order via an ADL algo using this account. |
| ADL Algo Approval Req | Shows whether a user can submit ADL algo orders in the account without approval. |
| TT Time Sliced/ TT Time | Shows whether a user can submit a TT Time Sliced or Time Duration order with the account. |
| TT Retry | Shows whether a user can submit a TT Retry order with this account. |
| Aggregator | Shows whether the account can be used to submit orders for aggregated instruments. |
| TT Timed | Indicates whether a user can submit a TT Timed order with this account. |
| TT Stop | Shows whether a user can submit a TT Stop order with this account. |
| TT If-Touched | Shows whether a user can submit a TT If-Touched order with this account. |
| TT Trailing Limit | Shows whether a user can submit a TT Trailing order with this account. |
| TT OCO | Shows whether a user can submit a TT OCO order with this account. |
| TT Bracket | Shows whether a user can submit a TT Bracket order with this account. |
| TT Iceberg | Indicates whether a user can submit a TT Iceberg order with this account. |
| TT Iceberg | Indicates whether a user can submit a TT Iceberg order with this account. |
| TT Order By Vol | Indicates whether a user can submit a TT OBV (Order By Volatility) order with this account. |
| TT Autohedger | Shows whether a user can submit a TT Autohedger order with this account. |
| Confirm Fills | Indicates whether users of the account can confirm fills. |
| TT With-A-Tick | SHows whether a user can submit a TT With-A-Tick order with this account. |
| Admin | Indicates whether the user has full administrator permissions. User restriction only. |
| Risk Admin | Indicates whether the user can set risk limits. User restriction only. |
| Structure Admin | Indicates whether the user can create or modify account structures. User restriction only. |
