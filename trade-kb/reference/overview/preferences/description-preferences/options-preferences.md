# Options Preferences

> Category: **Overview** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/overview/preferences/description-preferences/options-preferences/)

Use the Options tab to specify the level of precision displayed for Greeks and options risk metrics columns in all Options widgets.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/wrk-preferences-options.png)

To set the level of precision, click the drop-down list for each setting in the **Options Quantitative Value Precision** section shown below and select the number of decimal digits to display.

**Note**: Refresh each open Options widget after changing a value to display the new level of precision.

The “Options Chain” section contains the following setting:

**Number of Expiries exposed on Launch** — Sets how many expiries are displayed when the Options Chain (new) widget is opened.
