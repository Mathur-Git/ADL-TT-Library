# Positions Preferences

> Category: **Overview** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/overview/preferences/description-preferences/positions-preferences/)

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/wrk-preferences-positions2.png)

| Preference | Description |
| --- | --- |
| Display spread/strategy positions | Display the positions for parent spread and strategy orders in a Positions widget. |
| Display synthetic Autospreader positions | Sets whether to show or hide positions for synthetic Autospreader contracts. Uncheck this setting to hide positions for these contracts. |
