# Preferences Overview

> Category: **Overview** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/overview/preferences/description-preferences/preferences-overview/)

Each workspace includes preferences that allow you to customize workspace appearance and trading functionality. The settings apply to all widgets opened in your workspace unless you override the preferences in the widget’s local settings.

To open the Preferences dialog, click **Edit** | **Preferences** from the workspace menu bar.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/pref-preferences-open.png)

The Preferences dialog lets you make workspace customizations using the following tabs:

* [General](general-preferences.md)
* [Accounts](accounts-preferences.md)
* [Orders](orders-preferences.md)
* [Positions](positions-preferences.md)
* [Options](options-preferences.md)
* [Fills](fills-preferences.md)
* [Algos & Autospreader](algos-autospreader-preferences.md)
* [Sounds](sounds-preferences.md)
* [Hotkeys](hotkeys-preferences.md)
