# Customizing widget settings

> Category: **Overview** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/overview/widgets/task-widgets/customizing-widget-settings/)

Many Trade widgets allow you to customize the content, behavior, and appearance of their respective widgets. You can
access the widget settings from the widget’s context menu. The **Settings** section lists the things you
can customize in the widget. The **Defaults** section provides options for saving changes you make to a
widget as defaults for future widgets and to apply the changes to all other open widgets of the same type.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/widget-settings.png)

Some widgets, such as [MD Trader](../../../basic-order-entry/md-trader/reference-md-trader/md-trader-reference.md) and [Market Grid](../../../viewing-market-data/market-grid/reference-market-grid/market-grid-reference.md),
also let you select specific changes you want to save as widget defaults or for other currently open widgets of the
same type. These widgets include a **Selective update properties** setting that displays a list of widget
attributes you can save.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/mg-settings-defaults-1.png)

## Customizing Colors

From the widget settings, you can customize the cell or column colors in the following widgets:

* [Chart](../../../analytics/charts/description-charts/chart-overview.md)
* [Depth](../../../viewing-market-data/depth/description-depth/depth-widget-overview.md)
* [Fills](../../../order-management/fills/description-fills/fills-overview.md)
* [Market Grid](../../../viewing-market-data/market-grid/description-market-grid/introduction-to-market-grid.md)
* [MD Trader](../../../basic-order-entry/md-trader/description-md-trader/md-trader-overview.md)
* [Options Chain](https://library.tradingtechnologies.com/trade/opc-overview.html)
* [Options Electronic Eye](https://library.tradingtechnologies.com/trade/oee-options-electronic-eye-overview.html)
* [Options Risk](https://library.tradingtechnologies.com/trade/or-options-risk-overview.html)
* [Options Trade Monitor](https://library.tradingtechnologies.com/trade/otm-options-trade-monitor-overview.html)
* [Order Book](../../../order-management/order-book/description-order-book/order-book-overview.md)
* [RFQ Viewer](https://library.tradingtechnologies.com/trade/rfq-viewer-overview.html)
* [Spread Matrix](https://library.tradingtechnologies.com/trade/sm-overview.html)
* [Time and Sales](../../../viewing-market-data/time-and-sales/description-time-and-sales/time-sales-overview.md)
* [Trader Analytics](../../../analytics/trader-analytics/description-trader-analytics/trader-analytics-overview.md)

To customize colors:

1. Right-click in the opened widget and select **Settings**.
2. In the settings menu, click “+” next to **Colors** to display the available colors.
3. Click the box next to an option to open the color palette and select a color. Click **Custom** to create a
   customized color.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/gs-widget-custom-colors.png)
4. Click **Apply** and **Save**.

## Saving your customized widget settings as a custom widget

If you want to save the changes to the widget, while not changing the default widget behavior, you can make the
widget a custom widget. Saving your changes as a custom widget, allows you to create different versions of a widget
for different uses. For example, you could customize a Market Grid widget one way for treasuries and another way for
energies.

To save your changes as a custom widget:

1. Customize your widget as desired.
2. Right-click in the widget’s title bar and select **Save as custom widget** from the menu.
3. In the **Save Custom Widget** dialog, enter the following information for your custom widget:

   * Name for the widget, which is used in the widget title bar and in the **Widgets** menu.
   * In which search results you want the custom widget to appear.
   * Which icon you want to represent your custom widget.
4. Click **Save Widget**.
5. If you want this widget to appear as an icon in search results, set it as a [favorite](../description-widgets/widgets-menu.md#favorite-widgets) in the [Widgets](organizing-the-widgets-menu.md) menu.
