# Copying order data

> Category: **Overview** · [Source](https://library.tradingtechnologies.com/trade/overview/widgets/task-widgets/copying-order-data/)
>
> **Interpreted in:** [Platform & Workspace § Widgets](../../../../guides/platform-and-workspace.md#widgets)

You can copy order data from an entire row or an individual cell in grid-based widgets such as Order Book, Orders and
Fills,
Fills, and
Audit Trail. The data can then be pasted into any document or text field.

Note You can also use the drag-and-drop method to copy data between widgets. For more information, refer to the [Drag-and-drop
instruments between widgets](drag-and-drop-instruments-between-widgets.md) section of the help.

Copy the order data using one of the following methods:

* To select the entire row, left-click any cell.
* To select an individual cell:

* Hold down **Alt + left-click**, then press **Ctrl + C** to copy that cell.
**OR*** Hold down **Alt + right-click**, then select **Copy** from the menu.
