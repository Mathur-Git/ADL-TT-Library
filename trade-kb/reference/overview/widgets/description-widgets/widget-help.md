# Widget Help

> Category: **Overview** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/overview/widgets/description-widgets/widget-help/)

Each widget has a help icon (![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-help.png)) on its title bar that you can click to open help content specifically for that widget. The help widget that opens also provides access to additional online help topics in support of TT®.

If you request help for additional widgets, the content is displayed in the previously opened help widget. To close, click **X** in the help widget title bar.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/trade-widget-help.png)
