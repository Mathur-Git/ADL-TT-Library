# Frequently-Asked Questions (FAQ)

> Category: **Overview** · [Source](https://library.tradingtechnologies.com/trade/overview/tt-desktop/reference-tt-desktop/frequently-asked-questions-faq/)
>
> **Interpreted in:** [Platform & Workspace § TT Desktop vs browser access vs mobile](../../../../guides/platform-and-workspace.md#tt-desktop-vs-browser-access-vs-mobile)

1. **By default, TT Desktop installs to path: **C:Program FilesTrading Technologies**. Can it be moved to a different location?**Yes. You can select a different default folder location while running the default installer.
2. **Can TT Desktop be delivered via SCCM?**Yes. The default TTD executable file can be made into a Microsoft SCCM package to help manage deployments across multiple workstations. However, this method will not provide version control for the application.
3. **What updates do I need to manage for TT Desktop?**TT Desktop is a local executable that connects to the services of the TT platform. This executable may require occasional updates. The TT platform services do not reside on the users machine so TT Desktop is always accessing the most recent version of the TT platform.
4. **When TT Desktop is launched, will it attempt to download any updates? Where will those updates be stored?**

   Yes. The latest version of the front application code is downloaded when a user logs in. The application code is held in memory during the session, and is discarded when TT Desktop is closed or refreshed.
5. **Does the installation require an Internet connection?**

   Yes. An Internet connection is required for the download of the TT Desktop installer but is not required to run the installation.
6. **Can I get a static version of TT software?**No. A static version of TT Desktop is not available per the design of our software.
