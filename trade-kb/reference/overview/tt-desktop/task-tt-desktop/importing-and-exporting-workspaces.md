# Importing and exporting workspaces

> Category: **Overview** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/overview/tt-desktop/task-tt-desktop/importing-and-exporting-workspaces/)

TT Desktop allows you to save a configured workspace by exporting it as single files on your workstation. You can also give the file to others who can then import it to their own list of workspaces.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/ttd-import-export-dialog.png)

To export a workspace:

1. Save all changes in your workspace by clicking the **Save** icon.
2. Click the **File** button to open the menu.
3. With the File menu open, press and hold the **Shift** key and select **Import/Export**.
4. Click **Download the current workspace** to save a copy of the workspace as a file with the extension **.tws**.
5. Enter the name for the workspace file and click **Save**.
6. In the **Import/Export Workspace** dialog, click **Close**.

To import a workspace:

1. Save all changes in your workspace by clicking the **Save** icon.
2. Click the **File** button to open the menu.
3. With the File menu open, press and hold the **Shift** key and select **Import/Export**.
4. Click **Select File** to choose a .tws workspace file to upload.

   You can also drag and drop a **.tws** file under the **Select File** button.
5. Enter a name for the workspace, and click **Import**.

   **Note:** Refresh your browser to access the imported workspace.
6. In the **Import/Export Workspace** dialog, click **Close**.
