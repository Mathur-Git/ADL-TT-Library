# Downloading and installing TT Desktop

> Category: **Overview** · [Source](https://library.tradingtechnologies.com/trade/overview/tt-desktop/task-tt-desktop/downloading-and-installing-tt-desktop/)
>
> **Interpreted in:** [Platform & Workspace § TT Desktop vs browser access vs mobile](../../../../guides/platform-and-workspace.md#tt-desktop-vs-browser-access-vs-mobile)

## Downloading TT Desktop

To download the TT Desktop installation package:

* Method 1:

  1. In Microsoft Windows, [log in to TT](https://library.tradingtechnologies.com/trade/ttw-logging-in-to-tradett.html) through a browser.The following is displayed.

     ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/ttd-download-button.png)
  2. Click **Download now**.
  3. Save the **TTSetup.msi** file to the desired location on your file system.
* Method 2:

  1. In Microsoft Windows, [log in to TT](https://library.tradingtechnologies.com/trade/ttw-logging-in-to-tradett.html) through a browser.
  2. Open an existing workspace, or create a new one.
  3. From the workspace’s **File** menu, select **Download TT Desktop.**
  4. Save the **TTSetup.msi** file to the desired location on your file system.

**Note**: Alternatively, you can download the installer directly by entering the **trade.tt/desktop/download** URL in your browser.

## Installing TT Desktop

**Note**: If you have a previous version of TT Desktop installed on your system, you should manually uninstall it before proceeding.

To install TT Desktop:

1. Navigate to the location of the **TTSetup.msi** file you downloaded.
2. Double-click the **TTSetup.msi** file.

   ![TT Desktop run dialog](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/ttd2-install-1.png)
3. Click **Next** to install TT Desktop and progress through the installation dialogs. Then click **Finish** when the installation completes.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/ttd2-install-5.png)

   After the installation process completes, **Trading Technologies** icon (![TT Desktop icon](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/ttd-desktop-icon-small.png)) is placed on your desktop.

## Adding TT Desktop for a UAT environment

If your company has access to the UAT environment and your company administrator has given you permission to access the environment, you can also install TT Desktop for the UAT environment.

To add TT Desktop for UAT:

1. Download the **TTUatSetup.msi** UAT installation package from the UAT environment. Log into <https://uat.trade.tt>.
2. Double-click the **TTUatSetup.msi** file and following the installation instructions.
