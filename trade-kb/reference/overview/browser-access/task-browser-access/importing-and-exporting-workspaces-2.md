# Importing and exporting workspaces

> Category: **Overview** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/overview/browser-access/task-browser-access/importing-and-exporting-workspaces-2/)

The TT platform allows users to easily share a configured workspace as a single file. This allows you to save workspaces to your system. You can also give the file to others who can them import it to their workspaces.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/tt-plat-ws-import-export.png)

To export a workspace:

1. Save all changes in your workspace by clicking the **Save** icon.
2. Click the **File** button to open the menu.
3. With the File menu open, press and hold the **Shift** key and select **Import/Export**.
4. Click **Download** to save a copy of the workspace as a file with the extension **.tws**.

To import a workspace:

1. Save all changes in your workspace by clicking the **Save** icon.
2. Click the **File** button to open the menu.
3. With the File menu open, press and hold the **Shift** key and select **Import/Export**.
4. Click **Select File** to choose a .tws workspace file to upload.

   You can also drag and drop a **\*.tws** file under the **Select File** button.
5. Click **Import**.

   **Note:** Refresh your browser to access the imported workspace.
