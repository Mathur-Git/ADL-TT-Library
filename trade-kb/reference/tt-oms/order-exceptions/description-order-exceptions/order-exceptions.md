# Order Exceptions

>

> **Also in this section:** [Managing and resolving FIX care order rejections](../task-order-exceptions/managing-and-resolving-fix-care-order-rejections-2.md)

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/co-order-exceptions-scaled.png)

The Order Exceptions widget enables brokers and execution desk traders to efficiently manage and resolve FIX [care order](../../care-orders/description-care-orders/care-orders-overview.md) rejections.

Sell-side institutions and brokers require tools for handling rejected care orders while managing a high volume of client orders. The Order Exception Widget displays FIX care order rejections and provides tools such as Repair and Reject to address these orders directly.

FIX care orders with exceptions are only displayed in the Order Exceptions widget — not in the regular Order Book or Orders and Fills (OFW) widgets.

Note This feature is designed for high-touch desk users executing client orders. It does not cover administrative monitoring of FIX sessions, which remains outside the scope of this feature.

## Access and Visibility

To use the Order Exceptions widget:

* Users must be enabled for OMS Advanced features in TT Setup.
* Both the company-level setting “OMS Advanced Order Handling” and the user-level setting “OMS allowed” must be enabled.
* If OMS Advanced is not enabled, the menu item remains visible but disabled, with a tooltip: “Please contact your administrator to enable OMS Advanced features in Setup to access this widget.”
