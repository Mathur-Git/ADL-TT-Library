# Combine Display

> Category: **TT® OMS** · [Source](https://library.tradingtechnologies.com/trade/tt-oms/combining/description-combining/combine-display/)

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/cmb-combine-display-1024x177.png)

The display includes the following:

1. Combine pane — Appears when a user selects **Order Staging | Combine** option from either the Order Book or the Orders and Fills widget. This pane facilitates combining selected orders.
2. **Submit** button — Executes the specified action. When clicked, the selected orders are either bulked or stitched according to the suggested method.
3. **Include spreads** checkbox — If checked, the system will consider existing spread instruments when generating suggestions for the stitch action.
