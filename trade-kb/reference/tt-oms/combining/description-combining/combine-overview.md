# Combine Overview

> Category: **TT® OMS** · [Source](https://library.tradingtechnologies.com/trade/tt-oms/combining/description-combining/combine-overview/)
>
> **Interpreted in:** [Order Types & Execution § Care orders & the TT OMS lifecycle](../../../../guides/order-types-and-execution.md#care-orders-the-tt-oms-lifecycle)
>
> **Also in this section:** [Initiating an action from the Combine Screen](../task-combining/initiating-an-action-from-the-combine-screen.md)

The TT® OMS includes the Combine feature. This allows you to preview suitable combine actions, such as bulk or stitch, for multiple care orders.

When you select one or more care orders, the Combine screen suggests the following primary actions you can initiate directly.

xml encoding="utf-8" ?

| Action | Description | Primary Use Case |
| --- | --- | --- |
| Bulk | Combines two or more care orders (of the same instrument and side) into a single, larger parent order. | To more efficiently manage and execute multiple care orders as a single order. |
| Stitch | Combine care orders for different instruments. As an execution specialist or broker, you can stitch multiple orders together that comprise exchange-listed spreads. | To fill multiple care orders simultaneously and often at better prices due to more efficient spread markets. |

Care orders can be combined using the Order Book or the Orders and Fills widget.
