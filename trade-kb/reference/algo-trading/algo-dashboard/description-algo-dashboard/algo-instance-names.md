# Algo instance names

> Category: **Algo Trading** · [Source](https://library.tradingtechnologies.com/trade/algo-trading/algo-dashboard/description-algo-dashboard/algo-instance-names/)
>
> **Interpreted in:** [Algo Ops: Dashboard, Autotrader & Excel § From Algo Dashboard](../../../../guides/algo-ops.md#from-algo-dashboard)

When you launch an algo from Algo Dashboard, you have an option to specify a custom name for the instance of that algo. By default, the instance name is blank for algos with no template and matches the name of the template, if one is used. If you launch multiple instances of a single algo, you can assign custom names for specific instances to help you identify them in the Algo Dashboard order pane and in the [Order Book](../../../order-management/order-book/description-order-book/order-book-overview.md) widget. The instance name is displayed in the **TextTT** column.

![Instance name in TextTT column](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/alg-pane-orders-instance.png)

In this example:

* The first **Order Stack** algo instance uses **3×5 Stack** as a custom instance name.
* The second **Order Stack** algo instance does not use a custom instance name.
* The two **Random Disclosed Qty Order** algo instances both use **Disclose 3-10** for their instance names.
