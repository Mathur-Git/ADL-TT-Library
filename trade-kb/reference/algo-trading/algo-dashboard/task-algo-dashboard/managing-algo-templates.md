# Managing algo templates

> Category: **Algo Trading** · [Source](https://library.tradingtechnologies.com/trade/algo-trading/algo-dashboard/task-algo-dashboard/managing-algo-templates/)

### Creating an algo template

To create an algo template:

1. Click **Pick Algo**, and select the desired algo from the list of deployed algos.
2. Select **Manage templates** from the **New** drop-down menu.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/aut-algo-template-add.png)
3. Select **Add template**.
4. In the **Add template** dialog, enter a **Name** for the template, and click **Save**.

   The template is added to the drop-down.
5. Specify the desired algo parameter values, and click the ![Save](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-save-5.png) icon.

### Using an algo template

To use a template for an algo:

1. Select an algo from **My Algos** in the Autotrader widget.
2. Enter the number of instances of the algo template you want to instantiate.
3. From the **New** drop-down menu, select the template use.

   ![Select Template](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/aut-algo-template-use-1.png)
4. Make any desired changes to the algo parameters.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/aut-algo-template-use-2.png)
5. Click ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-open-algo-1.png) to launch the selected algo templates.

### Modifying an algo template

To modify an algo template:

1. Click **Pick Algo**, and select the desired algo from the list of deployed algos.
2. Select **Manage templates** from the **New** drop-down menu.

   ![Add-PIC](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/aut-algo-template-modify.png)
3. From the **Template** drop-down, select the template you want to modify.
4. Update the desired algo parameter values, and click the ![Save](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-save-6.png) icon.

### Setting a default algo template

You can select a default template to use in [Algo Dashboard](../description-algo-dashboard/algo-templates.md).

To set a default template for an algo in Algo Dashboard:

1. Select an algo from **My Algos** in the Autotrader.
2. Select **Manage templates** from the **New** drop-down menu.
3. Click the **Templates** drop-down menu.
4. Click the ![Star](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-yellow-star-2.png) icon for the template you want to make the default.

   ![Default Template](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/aut-algo-template-default.png)

### Deleting an algo template

To delete an algo template:

1. Select an algo from **My Algos** in Autotrader.
2. Select **Manage templates** from the **New** drop-down menu.
3. Click the **Templates** drop-down menu.
4. Click the **Delete** icon for the template you want to delete.
