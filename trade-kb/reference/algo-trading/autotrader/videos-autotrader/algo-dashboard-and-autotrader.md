# Algo Dashboard and Autotrader

> Category: **Algo Trading** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/algo-trading/autotrader/videos-autotrader/algo-dashboard-and-autotrader/)

## Video Summary

TT’s Algo Dashboard and Autotrader widgets let you launch and manage algos built using ADL or TT Algo SDK. Using the Algo Dashboard and Autotrader, you can launch an algo, modify its settings, and select a colocated data center nearest the exchange for server-side execution.
