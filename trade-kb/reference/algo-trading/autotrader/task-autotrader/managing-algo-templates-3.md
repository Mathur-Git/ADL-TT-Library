# Managing algo templates

> Category: **Algo Trading** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/algo-trading/autotrader/task-autotrader/managing-algo-templates-3/)

## Creating an algo template

To create an algo template:

1. Click **Choose an algo**, and select the desired algo from the list of deployed algos.
2. Select **Manage templates** from the **+ Add row** drop-down menu.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/at2-template-add-1.png)
3. In the **Add template** dialog, specify values for the desired algo instance parameters; then select **+ Add template** from the Templates drop-down.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/at2-template-add-2.png)
4. In the **Add template** dialog, enter a name for the template; then click **Save**.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/at2-template-add-3.png)

   The template is added to the drop-down.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/at2-template-add-4.png)

## Using an algo template

To use a template for an algo:

1. Select an algo in the Autotrader widget.
2. From the **+ Add row** drop-down menu, select the template to use.

   ![Select Template](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/at2-template-use-1.png)

   An instance is added populated with the values defined in the template.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/at2-template-use-2.png)
3. Make any desired changes to the algo parameters.
4. Click ![the Play icon](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-at2-play.png) to start the algo instance with the selected template.

## Modifying an algo template

To modify an algo template:

1. Select **Manage templates** from the **+ Add row** drop-down menu.An instance is added populated with the values defined in the template.

   ![Add-PIC](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/at2-algo-template-modify-1.png)
2. In the template flyout:

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/at2-algo-template-modify-2.png)

   1. From the Templates drop-down, select the template you want to modify.
   2. Update the desired values for the selected template.
   3. Click the ![Save](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/at2-icon-save-template.png) icon to save the changes.

## Setting a default algo template

To set a default template for an algo in Algo Dashboard:

1. Open an algo in Autotrader.
2. Select **Manage templates** from the **+ Add row** drop-down menu.
3. Click the **Templates** drop-down menu.
4. Click the ![Star](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-yellow-star-5.png) icon for the template you want to make the default.

   ![Default Template](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/at2-algo-template-default.png)

   **Note**: You can also click the ![Pencil](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/at2-icon-pencil.png) icon to change the template name.

## Deleting an algo template

To delete an algo template:

1. Open an algo in Autotrader.
2. Select **Manage templates** from the **+ Add row** drop-down menu.
3. Click the **Templates** drop-down menu.
4. Click the ![Star](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/at2-icon-delete.png) icon for the template you want to delete.
