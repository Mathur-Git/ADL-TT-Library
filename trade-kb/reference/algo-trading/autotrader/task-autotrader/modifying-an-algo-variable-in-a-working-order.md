# Modifying an algo variable in a working order

> Category: **Algo Trading** · [Source](https://library.tradingtechnologies.com/trade/algo-trading/autotrader/task-autotrader/modifying-an-algo-variable-in-a-working-order/)
>
> **Interpreted in:** [Algo Ops: Dashboard, Autotrader & Excel § Monitoring a running algo](../../../../guides/algo-ops.md#monitoring-a-running-algo)

You can modify working algos in Autotrader by changing the values of algo variables in of one or more of the algo rows.

To change a single variable for a working algo:

1. Verify the **SynthStatus** of the algo instance is **Working**.
2. Click and update the value you want to change; then click ![the pencil icon](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-pencil.png).

   **Note**: You cannot change the **Instrument**, **Co-location**, **Disconnect Action** or **Ignore Market State** values of a working algo order.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/at-modify-working-order.png)

To change multiple variables:

1. Verify the **SynthStatus** of the algo instance is **Working**.
2. Click the values you want to change in one or more algo instances.

   **Note**: You cannot change the instrument, co-location, or ignore market state values of a working algo order.
3. Click ![the pencil icon](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/icon-pencil-1.png) drop-down, and select **Apply All Changes**.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/at-modify-multiple-variables.png)
