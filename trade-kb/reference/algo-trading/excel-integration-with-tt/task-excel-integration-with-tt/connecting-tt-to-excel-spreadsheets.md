# Connecting TT to Excel spreadsheets

> Category: **Algo Trading** · [Source](https://library.tradingtechnologies.com/trade/algo-trading/excel-integration-with-tt/task-excel-integration-with-tt/connecting-tt-to-excel-spreadsheets/)
>
> **Interpreted in:** [Algo Ops: Dashboard, Autotrader & Excel § Excel / RTD linking](../../../../guides/algo-ops.md#excel-rtd-linking)

To connect TT to your Excel spreadsheet:

1. Log in to TT, and open a TT workspace.
2. Start Excel if it is not already running.
3. From the **File** menu, open the **Excel linking** sub-menu and select **Connect to Excel**.
4. The first time you connect to Excel, TT displays the following security dialog:

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/excel-allow-user-dialog.png)

   **Note**: The dialog might be obscured by the Excel window, so you might need to collapse or move the Excel window to see the dialog.
5. Click **Yes**.

   After successfully connecting to Excel, a new Excel icon is added to the menu bar, as shown.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/excel-enable-icon.png)

**Tip**: After the initial connection, you can enable and disable the connection to Excel by clicking the Excel icon in the menu bar.
