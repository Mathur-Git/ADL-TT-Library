# Autospreader Queue Holder

> Category: **Spread Trading** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/spread-trading/autospreader/videos-autospreader/autospreader-queue-holder/)

## Video Summary

Queue Holder is an Autospreader order type that submits multiple quotes at successive price levels and manages them as a group, optimizing each order’s position in queue. In this video we will learn how Queue holder works spread orders as well as how to activate Queue Holder for a spread.
