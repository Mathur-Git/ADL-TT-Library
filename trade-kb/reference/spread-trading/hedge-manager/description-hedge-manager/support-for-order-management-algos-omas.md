# Support for Order Management Algos (OMAs)

> **Interpreted in:** [Spread Trading: AutoSpreader, Aggregator, Hedge Manager § Hedge Manager](../../../../guides/spread-trading-autospreader.md#hedge-manager)

### Support for Order Management Algos (OMAs)

If you have created custom Order Management Algos (OMAs), using ADL® (Algo Design Lab), you can launch an algo for a working hedge order. The algo will then work the order according to its logic.
