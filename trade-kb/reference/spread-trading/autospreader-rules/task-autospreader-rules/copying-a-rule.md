# Copying a rule

> Category: **Spread Trading** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/spread-trading/autospreader-rules/task-autospreader-rules/copying-a-rule/)

### To copy a rule

1. Select a rule in the Autospreader Rule widget (e.g., Basic Slop)
2. Click **Copy**.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/asr-copy.png)

   The copied rule appears in the Autospreader Rules list (e.g., BasicSlop – copy). You can click the edit icon to rename the copied rule.
