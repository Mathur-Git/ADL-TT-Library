# Deleting a rule

> Category: **Spread Trading** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/spread-trading/autospreader-rules/task-autospreader-rules/deleting-a-rule/)

### To delete a rule

1. Select a rule in the Rule Manager (e.g., Basic Slop)
2. Click **Delete**.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/asr-delete.png)
3. Confirm the that you want to delete the rule and click **Yes**.
