# Editing a rule

> Category: **Spread Trading** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/trade/spread-trading/autospreader-rules/task-autospreader-rules/editing-a-rule/)

### To edit a rule

1. Click the edit icon next to a rule in the Autospreader Rules widget.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/asr-edit.png)

   The  **Edit Rule: (rule name)** screen appears.
2. Make the changes to the rule as needed as click **Save**.

   If prompted to confirm unsaved changes, click **Save Changes**.
