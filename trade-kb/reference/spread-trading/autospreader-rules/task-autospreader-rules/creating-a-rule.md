# Creating a rule

> Category: **Spread Trading** · [Source](https://library.tradingtechnologies.com/trade/spread-trading/autospreader-rules/task-autospreader-rules/creating-a-rule/)

To create a rule:

1. Click **Create Rule** in the Autospreader® Rules widget.

   You can also open the Autospreader Rules **Create Rule** screen in Autospreader by clicking the “+” in the Rules field.
2. Enter a rule name and description.
3. Select a [rule type](../description-autospreader-rules/autospreader-rules-configuration.md).
4. Select a [condition type](../description-autospreader-rules/autospreader-rules-configuration-logic.md).
5. Optionally, click the [**Custom Variable**](../description-autospreader-rules/autospreader-rules-configuration-custom-variable.md) tab to define your own variables for the condition or action logic.
6. Enter the [condition logic](../description-autospreader-rules/autospreader-rules-configuration-logic.md#condition-logic).
7. Click [**Add an Action…**](../description-autospreader-rules/autospreader-rules-configuration-actions.md) to select an action based on your rule type.
8. Enter the [action logic](../description-autospreader-rules/autospreader-rules-configuration-actions.md#action-logic).
9. Click **Save**.

   The rule appears in the Autospreader Rules widget’s list of rules, and can be selected in the Autospreader widget when configuring a spread.
