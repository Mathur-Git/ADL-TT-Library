# Opening Widgets in the Product Grid

> Category: **Viewing Market Data** · [Source](https://library.tradingtechnologies.com/trade/viewing-market-data/product-grid/task-product-grid/opening-widgets-in-the-product-grid/)

In the Product Grid, you can open a widget as one of the following:

* a stand-alone widget
* a linked widget

## Using a stand-alone widget

A stand-alone widget is populated with market data for an instrument selected in the Product Grid.

To use a stand-alone widget:

1. Right-click on an instrument row and select **Open** to show a list of widgets that can be opened from
   the Product Grid.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/pg-add-widget-1.png)
2. Click on a widget (e.g., Order Ticket) to select it.

   The widget opens and is seeded with market data for the selected instrument.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/pg-add-widget-2.png)

## Using a linked widget

A linked widget is populated with market data for a selected instrument, but updates automatically when you
select other instruments in the Product Grid.

To use a linked widget:

1. Right-click on an instrument row and select **Launch linked…** to show a list of widgets that can be
   linked to the Product Grid.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/pg-linked-widget-1.png)
2. Click on a widget (e.g., Depth) to select it.

   The linked widget opens with a yellow border.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/pg-linked-widget-2.png)
3. In the Product Grid, click a different instrument to select it.

   The linked widget (e.g., Depth) now contains the market data for the selected instrument.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/pg-linked-widget-3.png)
