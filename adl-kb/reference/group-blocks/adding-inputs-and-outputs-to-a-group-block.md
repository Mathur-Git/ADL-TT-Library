# Adding inputs and outputs to a Group block

> Category: **Group Blocks** · [KB Home](../../README.md) · [Source](https://library.tradingtechnologies.com/adl/group-blocks/adding-inputs-and-outputs-to-a-group-block/)

You can add ports to a Group block directly to the block or add them to the internal algo within the Group block.

### Adding a port to the Group block

To add ports to a Group block:

1. Right-click on the block and navigate to the type of connector and value type to pass through the port.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/gb-new-port-outside-block-1.png)

   The new port is added to the Group block.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/gb-new-port-outside-block-2.png)
2. Double-click the Group block to open it and notice the new input block.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/gb-new-port-outside-block-3.png)
3. Connect the new input block to the desired port.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/gb-new-port-outside-block-4.png)

### Adding a port from inside a Group block

To add ports to a Group block from within the block:

1. Double-click the group block to open it.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/gb-new-port-inside-block-1.png)
2. Anywhere on the ADL canvas (not on a block or edge), right-click to display the context menu; then select the type of connector and value type.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/gb-new-port-inside-block-2.png)

   The new port is added to the canvas.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/gb-new-port-inside-block-3.png)
3. Connect the new port to a block, if desired.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/gb-new-port-inside-block-4.png)
4. Return to the parent algo to see the new port on the block.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/gb-new-port-inside-block-5.png)
