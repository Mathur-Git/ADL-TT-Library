# Group blocks overview

> Category: **Group Blocks** · [Source](https://library.tradingtechnologies.com/adl/group-blocks/group-blocks-overview/)
>
> **Interpreted in:** [Design Patterns & Recipe Index § Organisation and reuse](../../guides/design-patterns.md#organisation-and-reuse)

Any set of blocks can be consolidated into a single Group block. In addition to the ease of replication and enabling a “cleaner” canvas, grouping a set of blocks allows the user to virtualize or save the group to a library for future use.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/gb-example-before-after.png)

### Ways to display a Group block

By default, a Group block is shown as a yellow square that shows its individual ports whose names match the names of their connected blocks. If you want to save space, you can also display a Group block in a collapsed form without identifying its ports.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/gb-collapsed-uncollapsed.png)

**Note:** **In the collapsed state, you cannot make new connections to the Group blocks ports.**

### Block properties

To customize the block, update the **Block Properties**.

| Property | Description |
| --- | --- |
| Name | Name to display beneath the block on the ADL canvas |
| Collapsed | Whether to display the block at its normal size, showing all its connectors, or to collapse it to a smaller size displaying only a single connection point. |
| Virtual | Whether to make the Group block a [virtual block](../virtualized-blocks/virtualized-blocks-overview.md). |
