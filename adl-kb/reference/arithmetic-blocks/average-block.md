# Average block

> Category: **Arithmetic Blocks** · [Source](https://library.tradingtechnologies.com/adl/arithmetic-blocks/average-block/)
>
> **Interpreted in:** [ADL Block Catalog § Arithmetic blocks](../../guides/block-catalog.md#arithmetic-blocks)

### Average block

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/ab-average-block.png)

The Average block adds the values from connected numeric input ports and divides the value by the number of used inputs, outputting a simple arithmetic average.

**Example:** The Average block calculates the average of its four used input ports and sends the value through its output port.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/ab-average-block-example.png)

### Block properties

To customize the block, update the **Block Properties**.

| Property | Description |
| --- | --- |
| Name | Name to display beneath the block on the ADL canvas |
