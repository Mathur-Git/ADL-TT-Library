# Multiply block

> Category: **Arithmetic Blocks** · [KB Home](../../README.md) · [Source](https://library.tradingtechnologies.com/adl/arithmetic-blocks/multiply-block/)

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/ab-multiply-block.png)

The Multiply block multiplies the first input and the second input and outputs the product.

**Example:** The Multiply block multiplies the Min Price Increment value by 3 to calculate a price three ticks away.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/ab-multiply-block-example.png)

### Block properties

To customize the block, update the **Block Properties**.

| Property | Description |
| --- | --- |
| Name | Name to display beneath the block on the ADL canvas |
