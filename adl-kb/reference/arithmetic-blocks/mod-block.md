# Mod block

> Category: **Arithmetic Blocks** · [KB Home](../../README.md) · [Source](https://library.tradingtechnologies.com/adl/arithmetic-blocks/mod-block/)

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/ab-mod-block.png)

The Mod block divides the first input by the second input and returns only the remainder.

**Note:** Dividing by zero will output **NaN** (Not A Number), which is not a valid input to other blocks.

**Examples:** With and without remainders

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/ab-mod-block-example.png)

### Block properties

To customize the block, update the **Block Properties**.

| Property | Description |
| --- | --- |
| Name | Name to display beneath the block on the ADL canvas |
