# Discrete blocks overview

> Category: **Discrete Blocks** · [Source](https://library.tradingtechnologies.com/adl/discrete-blocks/discrete-blocks-overview/)
>
> **Interpreted in:** [ADL Block Catalog § Discrete blocks](../../guides/block-catalog.md#discrete-blocks)

ADL provides a series of discrete blocks that allow you to perform actions when [discrete events](../adl-overview/adl-basic-concepts/description-adl-basic-concepts/continuous-vs-discrete-event-messages.md) occur. Each block can access information contained in the discrete message input.

Discrete blocks include:

* MsgInfoExtractor
* Value Accumulator
* Value Injector
* Value Extractor
* Value bucket
* Generator
* State
* Branch
* Funnel
* Discrete Min/Max
* Sequence
* Demultiplexer
* Moving Average
