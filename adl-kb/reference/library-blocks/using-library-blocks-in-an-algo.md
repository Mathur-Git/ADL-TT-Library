# Using library blocks in an algo

> Category: **Library Blocks** · [KB Home](../../README.md) · [Source](https://library.tradingtechnologies.com/adl/library-blocks/using-library-blocks-in-an-algo/)

After creating Library blocks, you can use them in any algo you create. To use a Library block in your algo, add it in one of the following ways:

- From the **File** menu, select **Load Library Block** and select the block to use.

  ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/lblk-load-library-block.png)
- From the context menu, click **Add Library Block** and select the block you want to add.

  ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/lblk-add-library-block.png)
- Search for the block using the **Search** field in the **Blocks** panel; then drag it to the canvas.

  ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/lblk-search-library-block.png)
The block is added to the canvas.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/lblk-load-library-block-2.png)
