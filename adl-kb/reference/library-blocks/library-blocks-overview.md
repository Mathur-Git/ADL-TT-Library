# Library blocks overview

> Category: **Library Blocks** · [Source](https://library.tradingtechnologies.com/adl/library-blocks/library-blocks-overview/)
>
> **Interpreted in:** [Design Patterns & Recipe Index § Organisation and reuse](../../guides/design-patterns.md#organisation-and-reuse)

ADL allows you to to save your custom group blocks as reusable Library blocks. When you save a group block as a Library block, ADL adds it to your collection of Library blocks allowing you to access the block when creating new or editing existing algos.
