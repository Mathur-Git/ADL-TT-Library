# Adding jump blocks

> Category: **Jump Blocks** · [Source](https://library.tradingtechnologies.com/adl/jump-blocks/adding-jump-blocks/)

To add Jump blocks:

1. Right-click on the output port of a block you want to send to another section of the algorithm, and select **Add jump block** from the menu that appears.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/jb-add-block-1.png)

   The anchor jump block (green arrow) is attached to the selected output port.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/jb-add-block-2.png)
2. Right-click on the anchor Jump block (green arrow) and select **Copy** from the context menu.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/jb-add-block-3.png)
3. Right-click once more elsewhere on the canvas and select **Paste** to place the destination Jump block (pink arrow).

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/jb-add-block-4.png)
4. Move the destination Jump block to the desired loction and connect the output port of the pasted Jump block to the input port of another block.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/jb-add-block-5.png)
