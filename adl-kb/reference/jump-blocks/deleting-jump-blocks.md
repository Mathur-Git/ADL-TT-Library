# Deleting jump blocks

> Category: **Jump Blocks** · [KB Home](../../README.md) · [Source](https://library.tradingtechnologies.com/adl/jump-blocks/deleting-jump-blocks/)

### Deleting Jump blocks

To delete Jump blocks, right-click on a Jump block and select **Delete** from the context menu.

**Note**: If you delete a source (green) Jump block, the selected block plus all of its destination blocks are deleted.
