# Virtual blocks video

> Category: **Virtualized Blocks** · [KB Home](../../README.md) · [Source](https://library.tradingtechnologies.com/adl/virtualized-blocks/virtual-blocks-video/)

### Video Summary

Virtualize group blocks to create multiple instances of their logic.

Virtual blocks create new instances, or copies, of themselves each time they receive a discrete message. In this video, we will demonstrate how a virtual block can manage multiple orders using the block of logic. We will also learn how to add a virtual block to an algo.
