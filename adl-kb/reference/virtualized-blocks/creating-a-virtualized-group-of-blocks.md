# Creating a virtualized group of blocks

> Category: **Virtualized Blocks** · [KB Home](../../README.md) · [Source](https://library.tradingtechnologies.com/adl/virtualized-blocks/creating-a-virtualized-group-of-blocks/)

To create a virtualized group of blocks:

1. Highlight a group of blocks and .

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/vb-create-virtualized-group-1.png)
2. Right-click on one of the selected blocks and select **Group**.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/vb-create-virtualized-group-2.png)

   The highlighted blocks become consolidated into a single block:

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/vb-create-virtualized-group-3.png)
3. In the **Block Properties** for the Group block, set the **Virtual** property to **True**. You can also choose **Virtualize** from the block’s context menu.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/vb-create-virtualized-group-4.png)

   The block’s border changes to a dashed line to indicate the block is a virtualized block.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/vb-create-virtualized-group-5.png)

   A new ‘copy’ of the virtualized blocks will be generated every time a discrete event message enters the virtualized block.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/vb-create-virtualized-group-5a.png)
4. If desired, you can double-click a virtual block to open it and display its logic in the canvas.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/vb-create-virtualized-group-6.png)

**Note:** A virtualized block must have a discrete event message input as it is created only when a discrete event message enters the block. See [Rules of Virtualization](rules-of-virtualization.md) for more information.
