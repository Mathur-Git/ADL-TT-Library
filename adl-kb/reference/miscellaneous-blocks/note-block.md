# Note block

> Category: **Miscellaneous Blocks** · [Source](https://library.tradingtechnologies.com/adl/miscellaneous-blocks/note-block/)
>
> **Interpreted in:** [Design Patterns & Recipe Index § Organisation and reuse](../../guides/design-patterns.md#organisation-and-reuse)

### Note block

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/mb-note-block.png)

The Note block lets you leave add or reminders throughout the canvas. The content of the Note blocks are typed into the Block Properties panel. The text within this block will not affect the logic or speed of the algorithm and will not be displayed anywhere else except on the image of the Note block.

**Example:** **The Note block describes the purpose of part of an algo**

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/mb-note-block-example.png)

### Block properties

To customize the block, update the **Block Properties**.

| Property | Description |
| --- | --- |
| Name | Name to display beneath the block on the ADL canvas |
| Text | Contents of the note |
