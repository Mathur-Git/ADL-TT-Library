# Random Number block

> Category: **Miscellaneous Blocks** · [KB Home](../../README.md) · [Source](https://library.tradingtechnologies.com/adl/miscellaneous-blocks/random-number-block/)

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/mb-random-number-block.png)

The Random Number block generates a random number between the user-specified minimum and the maximum, as follows.

* A discrete event message triggers the Random Number block.
* When triggered, the Random Number block generates a random number between the user-specified minimum and the maximum inputs.
* The block outputs a random number as well as passes the original message unchanged through the output message port.

**Example:** **Use the Random Number Generator block to generate random order quantities within a specified range**

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/mb-random-number-block-example.png)

### Block properties

To customize the block, update the **Block Properties**.

| Property | Description |
| --- | --- |
| Name | Name to display beneath the block on the ADL canvas |
