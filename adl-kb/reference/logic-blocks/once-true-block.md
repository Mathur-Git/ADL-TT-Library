> **Interpreted in:** [ADL Block Catalog § Logic blocks](../../guides/block-catalog.md#logic-blocks) · [Design Patterns & Recipe Index § Control flow](../../guides/design-patterns.md#control-flow)

### Once True block

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/lb-once-true-block.png)

The Once True block uses a Boolean input. If at any time the input becomes TRUE while the algo is running, the block output will remain TRUE for the duration of the algorithm’s execution.

### Block properties

To customize the block, update the **Block Properties**.

| Property | Description |
| --- | --- |
| Name | Name to display beneath the block on the ADL canvas |
