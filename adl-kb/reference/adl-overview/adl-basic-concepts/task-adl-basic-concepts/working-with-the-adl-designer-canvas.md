# Working with the ADL Designer Canvas

> Category: **ADL Overview, Concepts & Tutorials** · [Source](https://library.tradingtechnologies.com/adl/adl-overview/adl-basic-concepts/task-adl-basic-concepts/working-with-the-adl-designer-canvas/)

### Managing the display of the algo on the canvas

To zoom the canvas view in or out, use the mouse scroll button.

To zoom the algo so it fits entirely in the visible canvas, do either of the following:

* From the **View** menu, select **Zoom to Fit**.
* From the canvas’ context menu, select **Zoom to Fit**.

To pan the canvas to move out-of-view parts of an algo into view:

1. Press and hold the **Space** bar.
2. Press the left mouse button and drag the cursor.
3. When the desired part of the algo is visible, release both the **Space** bar and the left-mouse button.

### Managing views with bookmarks

To create [bookmarks](../description-adl-basic-concepts/adl-designer.md#bookmarks-menu) for a specific views of an algo:

1. [Pan and zoom](#manage-canvas-display) the canvas so it shows the area of the algo you want to save as a bookmark.
2. In the toolbar, click the **Bookmarks** menu and type the name for the bookmark in the field provided.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/abc-bookmark-add-2.png)

   **Note:** The first time you create a bookmark for an algo, the menu displays the following.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/abc-bookmark-menu.png)

To display a bookmarked view, select the desired bookmark from the **Bookmarks** menu.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/abc-bookmark-select-1.png)

You can also click the ![Edit](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/io-icon-edit.png) and ![Delete](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/io-icon-delete.png) icons to change the name of or delete a specific bookmark.

To search for a bookmark to use:

1. In the Blocks panel **Search** field, type “.” followed by all or part of the bookmark name.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/abc-bookmark-search.png)
2. Select the desired bookmark from the search results to update the canvas view.
