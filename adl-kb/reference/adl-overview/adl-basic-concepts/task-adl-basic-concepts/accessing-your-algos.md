# Accessing your algos

> Category: **ADL Overview, Concepts & Tutorials** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/adl/adl-overview/adl-basic-concepts/task-adl-basic-concepts/accessing-your-algos/)

Algos you create using ADL are associated with your TT login, so you can open and save them from any system. You can also export and import algos as JSON (**.json**) files if you want to backup your algos or share them with other users.

* [Opening and saving an algo](#open-save-algo)
* [Importing and exporting algos](#import-export-algos)

### Opening and saving an algo

To open an algo:

1. From the **File** menu, select **Open**.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/adf-open-algo-1.png)
2. Click the desired algo.

   The selected algo opens on the canvas.

   ![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/adf-open-algo-2.png)

  

**Note:** You can open TT Public Algos, such as the OCO algo, to see the algo logic. You cannot modify the algo, but can use **Save As** to save a copy that you can modify.

To save an algo:

1. From the **File** menu, select **Save** or **Save As**.
2. Specify the name for the algo and provide a description, if desired.
3. Click **Save**.

### Importing and exporting algos

To import an algo:

1. From the ADL Designer Toolbar **File** menu, select **Import**.
2. Locate the algo **.json** file in your filesystem.

   The algo is imported and opens on the canvas.

To export an algo:

1. From the ADL Designer Toolbar **File** menu, select **Export**.
2. In the file dialog, specify the name and location of the **.json** file.
