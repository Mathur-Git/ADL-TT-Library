# Introducing the new ADL canvas

> Category: **ADL Overview, Concepts & Tutorials** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/adl/adl-overview/introduction-to-adl/description-introduction-to-adl/introducing-the-new-adl-canvas/)

In an effort to improve performance, especially for larger ADL algos, TT has completely redesigned the TT ADL canvas. The new underlying technology not only improves performance, but also provides new features that let algo developers more easily add blocks to the canvas, more quickly locate existing blocks that are not currently visible in the displayed canvas area, and more efficiently identify potential connection pathways between blocks.

![](https://library.tradingtechnologies.com/wp-content/uploads/2025/12/new-adl-intro-annotated.png)

1. New [search feature](../../adl-basic-concepts/description-adl-basic-concepts/adl-designer.md#block-panel) helps you filter blocks and fields.
2. Always-visible [Block Properties](../../adl-basic-concepts/description-adl-basic-concepts/adl-designer.md#block-properties) let you see a block’s functionality at a glance.
3. Highlighting [potential connections](../../adl-basic-concepts/task-adl-basic-concepts/adding-connecting-and-arranging-blocks.md#edge-finder) lets you create a connection with a click.
4. [Bookmarks](../../adl-basic-concepts/description-adl-basic-concepts/adl-designer.md#adl-designer-toolbar) for different views of the displayed canvas area help you quickly bring portions of a large algo into view.

Additionally, the new ADL redesigned the [Formula Editor](../../advanced-concepts/description/formula-editor.md) to make it easier to enter formulas.
