# What is ADL?

> Category: **ADL Overview, Concepts & Tutorials** · [KB Home](../../../../README.md) · [Source](https://library.tradingtechnologies.com/adl/adl-overview/introduction-to-adl/videos/what-is-adl/)

### Video Summary

ADL’s visual programming environment features an intuitive drag-and-drop interface, where traders can use a collection of functional blocks to access market data, build complex logic, submit orders and monitor market states. In this video we will show you how ADL let’s traders build algorithmic trading strategies using blocks and edges, we’ll discuss some of the types of algos you can create with ADL and we’ll demonstrate how you can test your algos in ADL and deploy them for use in TT.
